# 4,000㎢の島国から世界の舞台へ：FIFAワールドカップ2026、カーボベルデの軌跡🇨🇻

🌍 デモサイト  
https://furuhashilab.github.io/Youth1/

## 概要

このプロジェクトは、**2026 FIFAワールドカップ出場国の一つであるカーボベルデ**に焦点を当てた、**3Dストーリーマップテリング**です。

ユーザーは3D地図上を移動しながら、カーボベルデがワールドカップ出場に至るまでの背景と試合結果をストーリー形式で体験できます。

---

## 主な機能

- 🌍 3D地図によるカーボベルデの可視化
- 📍 各スポットへの自動フライアニメーション
- ⚽ 2026 FIFAワールドカップ初出場に関するストーリー
- 📱 PC・スマートフォンに対応したレスポンシブデザイン
